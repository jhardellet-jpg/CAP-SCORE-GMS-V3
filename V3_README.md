# CAP SCORE GMS® V3

V3 est un dépôt de développement séparé, créé depuis la V2 originale.

## Règle de sécurité
La V2 est sanctuarisée et n'est jamais modifiée par les travaux V3.

## Objectifs V3
1. Rapport PDF automatique et double envoi email.
2. Moteur d'interprétation et recommandations priorisées.
3. Suppression de la fausse protection par mot de passe côté navigateur.
4. Préparation d'une architecture serveur pour les secrets, l'envoi email et le futur paiement.
5. Conservation du questionnaire et du scoring V2 pendant la phase de sécurisation.
